# Analysis Notebooks for the Red Earth East Complex Fire PyroCb Event

Analysis notebooks accompanying the study of the Red Earth East Complex PyroCb event in Alberta, Canada, in May 2025.
The repository contains the Jupyter notebooks used to generate the analyses and figures presented in the associated publication.

To run the notebooks, please follow these steps: 
1. Download the post-processed ICON HAM-lite simulation output from https://www.wdc-climate.de/ui/entry?acronym=DKRZ_LTA_1174_ds00004
2. Download the additional data such as observations, grid-info and more from the Zenodo repository
3. Adjust the paths and run the Notebooks
